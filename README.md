# 不簡單的日常幸福

1920×1080 固定解析度的互動介面。

## 放上 GitHub Pages
1. 把這個資料夾裡的所有檔案放到 repo（保持檔名不變）。
2. Settings → Pages → 選擇分支後儲存，開啟產生的網址即可。

## 本機測試
場景的遮罩圖片無法用 file:// 直接開啟，請用本機伺服器：

```
python3 -m http.server 8000
```
然後開 http://localhost:8000

## 注意
- 字型從 Google Fonts 載入，展場電腦需連網；若要離線使用，請改為本機字型檔。
- 網址加上 #ayumom、#mei、#zhiming 可直接進入各角色場景。
